BTCE505P - Artificial Intelligence Lab (Set A)
Beginner-friendly practical programs

Files included:
1. Practical_1_Matrix_Operations.py
2. Practical_2_BFS_DFS.py
3. Practical_3_Probability_Bayes_Rule.py
4. Practical_4_Tower_of_Hanoi.py
5. Practical_4_Tower_of_Hanoi.pl

How to run Python files:
1. Install Python.
2. For Practical 1, install NumPy using: pip install numpy
3. Open Terminal or Command Prompt in this folder.
4. Run a program using: python filename.py

For example:
python Practical_1_Matrix_Operations.py

Practical 4:
- The .py file is the beginner-friendly Python version.
- The .pl file is the Prolog version requested in the question paper.
- In SWI-Prolog, load the file and run: hanoi(3, a, c, b).

Note:
Each Python program starts with print("IAR/17360").
